# Rules decisions in code (W7)

Every place where Soul Forge decides a rule that the content data does not state. Each row gives the rule, the book
and passage it follows, where the code decides it, and the test named for it. Started on 2026-11-17 with the decisions
made or found that week. The sweep of older decisions was done on 2026-11-20: every comment in src that cites a book
was read, and each decision behind one that had no row got one. Four rows name no test of their own yet ("None of its own"); they are the open part of W7.
