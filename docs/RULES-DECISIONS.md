# Rules decisions in code (W7)

Every place where Soul Forge decides a rule that the content data does not state. Each row gives the rule, the book
and passage it follows, where the code decides it, and the test named for it. Started on 2026-11-17 with the decisions
made or found that week; older decisions are added as the W7 sweep reaches them.

| A spell list widened for spells (2024 Magical Secrets) does not widen cantrip choices, unless the feature names cantrips (Divine Soul). A list of named spells counts as written.                                                           | PHB 2024, Bard, Magical Secrets ("your new prepared spells"); XGE, Divine Soul ("a sorcerer cantrip or a sorcerer spell")                | `src/aurora/engine.ts`, `extendCantrips` and `resolveSupports`                                 | `src/aurora/extendCantrips.test.ts`                         |
