# Rules decisions in code (W7)

Every place where Soul Forge decides a rule that the content data does not state. Each row gives the rule, the book
and passage it follows, where the code decides it, and the test named for it. Started on 2026-11-17 with the decisions
made or found that week; older decisions are added as the W7 sweep reaches them.
